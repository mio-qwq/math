## Algorithm follow-up: precise prior constraints and parameters

Cire and van Hoeve, [Multivalued Decision Diagrams for Sequencing Problems](https://www.andrew.cmu.edu/user/vanhoeve/papers/mdd_sequencing.pdf), author manuscript revised May2013, section9, Lemma8 and Theorem3, explicitly study discrepancy precedences j_p before j_q for q>=p+k and prove an MDD-width bound2^(k-1). At k=B these are exactly R1's added all-prefix edges. This is direct prior art for that constraint family and its exponential local-state representation; their sequencing objective and parameter are not automatically the variable-W c1 parallel optimum. The primary agent opened the original PDF and checked the relevant section.

The [independent algorithm novelty review](subagents/literature/FORCED_SEGMENT_NOVELTY.md) also examines Munier-Kordon's2021 time-window-overlap parameter and a2026 improvement, and Munier-Kordon–Hanen's19March2026 [A New Parameter for Scheduling Dependent Tasks](https://graal.ens-lyon.fr/~yrobert/slides-frejus/Munier.pdf). The latter author slides describe FPT scheduling in incomparable-graph degeneracy; the associated SSRN6403481 full text was inaccessible. The primary agent opened the slides. Neither the talk nor an abstract is treated as an independently verified full proof. Degeneracy can equal W on N=B=W+1 independent jobs, and time-window overlap can grow with W even when c=S=0. Thus the inspected parameter bounds alone do not imply R20 or R21. Source status, exact scopes, access gaps and search queries remain recorded in the independent note; historical priority is still unconfirmed.

## Strong follow-up predecessors: lookahead and hardness

Feder, Motwani, Panigrahy, Seiden, van Stee and Zhu, [Combining Request Scheduling with Web Caching](https://ir.cwi.nl/pub/4063/04063D.pdf), CWI SEN-E0402, March2004, section1, Theorems3--5 and7, is close prior art. It uses the same occupied-prefix window convention; cache misses replace parallel makespan. It already has3/2 and5/4 lower bounds, final-item indistinguishability and inverse-lookahead bounds with offline chunk planning. The primary agent read the original report. No objective-preserving equivalence was established. See [LOOKAHEAD_NOVELTY.md](subagents/literature/LOOKAHEAD_NOVELTY.md), which also reads Motwani--Saraswat--Torng1998 on multipass assembly lines. R23/R24 prove statements for R1, not the first occurrence of these ideas or numerical patterns.

Jansen, Land and Kaluza, [Precedence Scheduling with Unit Execution Time is Equivalent to Parametrized Biclique](https://doi.org/10.1007/978-3-662-49192-8_27), SOFSEM2016, pp.329--343, is direct prior art for makespan-three/biclique and height-two scheduling. The independent reviewer read the publisher's public abstract and Appendices B/C (Appendix C Lemma1); the main body remains inaccessible. Our c=k ordered-window embedding is reviewed in [EXCESS_HARDNESS_NOVELTY.md](subagents/literature/EXCESS_HARDNESS_NOVELTY.md). It must not be called the first such scheduling reduction.

Bingkai Lin, [The Parameterized Complexity of k-Biclique](https://arxiv.org/abs/1406.3700v3), version3 revised8June2019, section1.1 Corollary1.3, supplies the imported W[1]-hardness. Root and theory reviewers read the original proof context: this hardness uses a deterministic parameterized reduction; randomized-ETH qualifications concern a separate stronger bound. R25 does not reprove that source theorem. The same independent note checks van Bevern et al.2016's observation that an older unrestricted-poset reduction has width=machines+1; that graph class is broader than the supplied ROB order and does not contradict R21.
