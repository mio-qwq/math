# 密码分析研究机会报告

调查截止：**2026-10-11，UTC**。仓库基线：`a8c3f22e26b08c2d294e2b0e6df2d9cfa430cda0`。本报告属于 **L0 文献调查与研究决策**，不是新攻击公告。

## 1. 决策

第一研究方向选择 **ChaCha 前三次模加的精确有符号相关、适用条件与固定常量输入**。目标是从明确的小结构推导可核验公式，检验跨加法依赖何时可以消去、何时必须保留，并寻找真正降低精确计算成本或改善分析界限的结构。本段与初始排序保留调查时判断；文末记录实际研究后对这一窄选题的降级与转向。

选择理由：局部运算可完整定义，小字长可以全枚举，标准32-bit实例可尝试证明与状态消去；近期原始论文明确显示相关性模型仍有误差。不过，普通模加自动机、连续模加不独立、ChaCha半个quarter-round精确差分均已有先行工作。**这些现象和常规实现只作为基线，不能预先登记为原创。**

备选顺序：Keccak条件线性结构与可检查证书；合法状态约束下的BLAKE3差分可实现性；ML-KEM保留依赖的概率/旋转轨道计数；Ascon标准宽度trail界限。

完整SHA-256碰撞/原像、完整AES单密钥显著改进、一般RSA快速分解和标准参数格筛突破仍有极高价值，但目前没有与可用资源匹配的具体方法，不作为首个实验周期承诺。

## 4. 各算法的安全对象与已核前沿

下列是决策用摘要，详表和读取程度在分组调查中。出处使用对应附件的来源ID，均链接原始来源。

### 4.1 SHA-256 / SHA-512

FIPS180-4规定SHA-256为64步、SHA-512为80步；分别保持32/64-bit字长、标准IV与填充。2026/1120的2026-09-09修订预印本报告：38步SHA-256碰撞`2^104.3`，38/39步SHA-512为`2^125.4 / 2^178`，内存报告为negligible；36步SHA-256报告消息对。这里仅核作者摘要/版本，未重跑消息对。[H01,H06]

EUROCRYPT2026与CRYPTO2026的先行路径搜索也须比较。2024的39步SFS结果不能替代标准IV纪录；52/57步SHA-2的相关旧结果属于pseudo-preimage，不应写成普通完整哈希原像。[H07–H12]

潜在增量是消息扩展条件、Boolean位关系、可控制部分与未控制概率之间的新约束；高价值难点是保留标准消息模型同时跨越现有瓶颈。普通SAT碰撞复现不新。

### 4.2 SHA-3 / Keccak

FIPS202标准宽度1600、24轮，SHA3与原始Keccak的域分隔不同。2024内部差分碰撞已经涉及5轮SHA3-384/6轮SHAKE256；2025内部差分原像涉及若干5轮实例。2026 CT-RSAC对4轮SHA3-384给出进一步复杂度改进。不能把不同capacity、输出长度或800-bit Crunchy实例合并为一个标准纪录。[H02,H13–H18]

重点研究χ条件线性化后的真实秩、仿射空间相交、SAT连接的冗余条件与合法消息约束。有限域计算与证书适合独立验证；未经新最优性或复杂度证明的DDT/VDDT生成只是L0。

### 4.3 BLAKE2 / BLAKE3

BLAKE2s/b分别10/12轮；BLAKE3为7轮并包含树模式、flags、counter和输出模式，按设计者明确安全目标评价。2023/299的全7轮BLAKE3 boomerang针对keyed permutation，作者报`2^180`，不是标准树哈希碰撞，也没有突破其128-bit目标。BLAKE2模式安全与BLAKE3类树/XOF条件已经有证明研究。[H03–H05,H20–H25]

值得推进的是带合法初始化与消息约束的联合概率、可实现性证书，以及与近似signed-difference模型相比的新必要条件。低轮先构成基线；升为论文候选需要可推广定理或同模型实质改进。

### 4.4 SHA-1

完整80步普通碰撞已在2017实际完成，2020还有chosen-prefix攻击；碰撞安全破坏不等于完整原像安全被破坏。公开条件与向量适合独立验证器，昂贵全碰撞重做不适合首轮。潜在价值是可证明更优的条件集合或向仍在使用的算法迁移的新方法。[H26–H29]

### 4.5 AES-128 / AES-256

FIPS197的2023更新没有修改算法；二者分别10/14轮，块长均128位。2026 CiC的低数据DS-MitM研究明确改善缩减轮模型，但其7轮AES-128与9轮AES-256仍涉及约`2^116.8 / 2^241.5`个128-bit状态的内存规模。只报低数据量会掩盖整体不可行性。更多在线/离线成本见附件表。[AESSTD,AES26]

2026 cross-ratio预印本与2025 chosen-key全轮区分结果直接占据若干相近方向；尚未取得的正文阻止相关新颖性认定。首次可做GF(256)联合条件/假阳性计数，但必须给同模型新界限，而非把chosen-key结果解释为通常单密钥恢复。[AESCR,AESCK]

### 4.6 ChaCha20

RFC8439规定256-bit密钥、32-bit计数器、96-bit nonce、32-bit字长、20轮及feed-forward。自由内部状态的局部性质不直接等于标准固定常量/固定密钥模型。[CHSTD]

2026-10-09的正式论文用截断路径簇和实测相关更新缩减轮资源估计，同时明确未完整控制簇外尾项；它指出跨加法carry依赖与有符号聚合值得改进。2025 ToSC更正论文否定的是指定分析，不是所有7轮结果。[CH26,CORR]

首项工作将以精确局部公式为目标。Qin–Wu连续模加、Bellini等half-quarter状态函数、Okada两次模加线性近似和最近Li等推导规则均是先行门槛。普通carry DP与小字长乘积偏差归L0。[ARX2,CHREF,CHDER]

### 4.7 Ascon

SP800-232于2025定稿；标准AEAD128来源于Ascon-128a，标准与旧版本大小端、IV等不同。旧版低轮free-start碰撞不是标准Hash256碰撞。2025已有更好的SAT/MILP模型，2026有commitment相关新研究，不能把未读正文的范围当作空白。[ASSTD,ASCODE,ASALG,ASMODEL,ASCOM]

备选目标是标准宽度下可独立检查的trail不可满足/最优性证书，或真实收紧的差分线性界限；版本迁移跑通和5-bit S-box表重建本身是L0。

### 4.8 RSA

分别研究一般因子分解、RSA inversion、OAEP/PSS安全，不把它们宣称已知无条件等价。本次检索到的一般形式分解强公开基线仍为RSA-250（829bit，2020）；原始机构报告的资源为数千core-years，非当前可执行任务。[S01,S19–S22]

可行中间问题是某个明确Coppersmith格族的行列式、单项式选择与根恢复条件；仅得到短向量不证明得到根。弱私钥/泄漏模型结果不能泛称标准RSA突破。

### 4.9 ECDSA / Ed25519

ECDSA以FIPS186-5和明确nonce模型为准；Ed25519须保留RFC8032中的SHA-512、编码与cofactor验证。2021及2023已有Ed25519具体变体安全证明，2026又有高级绑定概念框架；ECDSA近期key-recovery绑定结果也有明确额外模型。[S02–S04,S12–S16,S23–S25]

潜在目标是安全概念之间的新严格蕴含/分离或归约界。nonce重用代数、不同验证规则的普通演示、把哈希替换成1轮Ascon后的弱化实例，不能宣布标准签名被破坏。

### 4.10 ML-KEM

FIPS203的最终参数、诚实正确性、适应性δ-correctness与IND-CCA归约分别建模。CRYPTO2025已有修正dual-attack模型，CRYPTO2026已有利用环结构的hybrid改进；稀疏FHE的大幅收益不能转录为标准ML-KEM收益。相关2026/279与2026/366有最新修订及定理更正。[S05,S07–S10]

可选中间问题是q=3329压缩映射的联合分布，或旋转猜测事件的精确并集概率。既有2022非独立性研究、2025形式化概率界及2026新预印本线索必须先比对；未读到的新预印本只作为缺口，不背书其证书。[S11,S17,S18,S26]

### 4.11 ML-DSA

FIPS204的最终三套参数、拒绝条件与随机预言模型不可省略。2025 restricted-SVP工作有具体估计，旧2022/1601预印本已withdrawn，不能列为当前确证结果。[S06,S27,S28]

可行理论问题是稀疏challenge乘秘密的联合事件或统一拒绝概率界；不能用平均迭代次数自动推导每个密钥的独立几何尾，也不能把跳过拒绝步骤的弱化实验称为标准攻击。

## 5. 报告必须回答的五个问题

**哪些相对容易有新颖增量？** 精确局部计数、依赖条件、自动化模型的可检查约束、带完备证据的小范围最优性比追逐完整密钥恢复现实。ChaCha/ARX、Keccak结构和合法BLAKE3状态是优先候选，但“比较容易”仍不意味着一定新颖。

**哪些最重要但突破概率极低？** 完整标准SHA-256原像/碰撞、完整AES/ChaCha的实质单密钥攻击、一般RSA/标准曲线DLP、标准格参数的大幅算法降阶。当前缺乏可执行新方法；简单扩大暴力规模没有研究理由。

**哪些值得长期投入？** 可证明的自动化密码分析、依赖保持的有符号相关、合法消息/密钥模型的可实现性、格密码具体安全与正确性界。它们能积累可迁移方法，而不仅是一个低轮数字。

**哪些已有方法可能得到真正复杂度改进？** ARX的状态消去若减少必须保留的carry/旋转边界；Keccak连接若获得新秩/蕴含条件；SHA-2局部路径若减少未控制条件且保留标准消息；ML-KEM轨道计数若替换过松独立估计。它们是待验证机制。solver运行时间下降、模型分母改变或更弱IV假设均不自动等于攻击复杂度改善。

**第一篇论文优先选什么？** 优先做“ChaCha局部结构的精确有符号相关和可证实依赖条件”，先尝试一个严格、能在标准32-bit参数验证的窄命题。若查重覆盖，则及时转到固定常量或重叠位区；若仍没有新定理，不为了论文而夸大，应保留L0验证工具并转向备选。

## 6. 立即执行的第一研究周期

设独立均匀n-bit字`a,b,c,d`，加法模`2^n`，定义

```
s = a + b
t = rotl(d xor s, r)
u = c + t
v = rotl(b xor u, q)
w = s + v
```

令`L`为同一运算序列中三次加法全部替换XOR所得输出。对每个输出位i，研究**有符号相关**

`C_i = 2^(-4n) sum_{a,b,c,d} (-1)^(bit_i(w xor L))`。

标准局部运算参数`n=32,r=16,q=12`。这只是quarter-round前三次模加的自由均匀输入模型，不是完整ChaCha20区分攻击。再单独研究固定a的常量模型，其分母为`2^(3n)`；不混合两者。

验收：独立枚举/推导交叉一致；保留符号而非绝对偏差；写出全部适用条件和边界；标准参数不靠toy外推；每项结果记录源码hash、命令、退出码、整数分子分母。对新候选立即做第二级原创性审查，禁止因公式正确就授予L2。

## 8. 同日实际研究后的优先级修订

初始选择已实际执行多个完整子周期，详见[阶段报告](projects/chacha-three-add/RESULTS.md)。特殊位、固定首字、全部标准输出位及一般计数均得到数学与程序证据；随后[具体旧方法重构](projects/chacha-three-add/literature/METHOD_COMPARISON.md)证明关键矩可由普通有限状态理论简短推出。固定a,b,c的跟进同样是常量核直接应用，见其[查重报告](projects/chacha-three-add/scouting/fixed_abc/NOVELTY_REVIEW.md)。

因此，对**这个特定all-XOR掩码及条件化问题**，将“重要性/原创机会/近期原创增量可行性”的决策分数调整为9/2/4，按原权重得4.9。重要性不变；降低原创机会是因为关键矩和算法已被具体旧框架重构，降低近期原创增量分数是因为剩余贡献必须跨越近邻全文比较和实际攻击用途两项未完成门槛。这不是对整个ChaCha密码分析领域降分，也不是历史原创概率的统计估计。初始15项排序保留为选择时的记录。

**当前第一篇论文候选主线改为Keccak公开实例的全局投影计数界。** 同日后续查重发现[Yan–Bao–Li，SAC2026/ePrint2026/2090](https://eprint.iacr.org/2026/2090)已直接覆盖一般秩/自由度优化、容量投影重数、调和平均校正和精确单纤维计数。作者也已公开提出直接优化有效自由度。因此，不能把初筛中尚未查到的文章视为不存在，也不能把宽泛研究动机作为新贡献。

已取得官方35页会议稿并审读相关章节；下一目标严格限定到同一Table6实例的非平凡全局二阶矩、投影大小或有效自由度可检查界。文献使用800位内部差分坐标、R412/C388，padding计入容量；核维数28与局部有效集合分解尚待独立复算。一般Cauchy–Schwarz界、自相关公式和普通枚举都是L0基线。最新09-30修订的ePrint正文未得；当前不增加机会评分，不声称比已有方法更强。

完整版本区别、四组最近邻与代码读取边界见[近期补充](projects/keccak-conditional-rank/RECENT_LITERATURE.md)。[下一目标](projects/keccak-conditional-rank/OBJECTIVE.md)已记录成本门槛、独立验证方式与失败标准；本阶段没有运行Keccak攻击实例。

这个修订体现的是选题失败后的证据驱动调整：保留可靠的L0工具和未历史澄清的应用命题，不把完成实验的投入当作认领原创的理由。
