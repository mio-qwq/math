# El Zein–Mortada Conjecture 1

## Scope

Every finite simple subcubic graph whose degree-three vertices are independent and each lie on a cycle of length at most four has a (1,2,3,4)-packing coloring. Arbitrary connector lengths, leaves and disconnected graphs are included. This is [arXiv:2603.25113v1 §5 Conjecture 1](https://arxiv.org/html/2603.25113v1#S5).

## Dependencies and prior theory

Self-contained structural classification and explicit tiles in PROOF.md.

The all-even connector subclass follows from Lemdani–Abbas–Ferme (2020), Proposition 2.8 and subgraph monotonicity. This proof additionally handles odd/mixed connectors and endpoint types.
