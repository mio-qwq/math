# 原猜想、已有理论与历史边界

James Tuite、Elias John Thomas、Ullas Chandran S.V.，
*On some extremal position problems for graphs*，Ars Mathematica Contemporanea
25(1) (2025), #P1.09，[DOI:10.26493/1855-3974.3094.bc6](https://doi.org/10.26493/1855-3974.3094.bc6)。
原 Conjecture 4.5 位于印刷页 17；可查
[期刊原稿](https://oro.open.ac.uk/92086/13/92086final.pdf) 与
[arXiv:2106.06827v3](https://arxiv.org/pdf/2106.06827v3)。

原命题为：每个整数 n≥11，都存在 n 阶有限简单无向循环图，直径为 2，
monophonic position number 为 2。本目录证明 n=15 时无任何这样的循环图，
故严格否定这一全称存在性猜想。反例不是单张不符合条件的图。
去掉循环图限制后的一般图存在性 Theorem 4.4 不被此结果否定。

三角形与相同开放邻域的独立点所给出的 monophonic 障碍，以及循环群 Cayley
表示，属于通用已有理论。完整结果依赖这些障碍对该阶全部连接集的排除，
而不是声称这些通用方法本身为新发现。

2026-10-10 的结果后独立复查重新读取原预印本当前 v3、原期刊的定义与命题
索引，并核对 [The General Position Problem: A Survey v5](https://arxiv.org/html/2501.19385v5)。
该综述公开于 2026-08-16，仍复述此猜想，并明确循环图为循环群的 Cayley 图。
原期刊 PDF 本轮直接访问受限，期刊命题通过原始公开索引与成功访问的 v3
正文交叉核对；不声称成功下载整份期刊 PDF。

经多轮后续文献、勘误、反驳声明和作者公开记录检索，在实际核读范围内未
定位同范围的更早完整反驳。访问和索引覆盖有限，这不能证明此前不存在结果。
**历史首创性及绝对开放性尚未确认，不作世界首次或优先权声明。**
若出现更早或新的解答，应重新核对原图对象、全部誘导路径量词与证明内容。
