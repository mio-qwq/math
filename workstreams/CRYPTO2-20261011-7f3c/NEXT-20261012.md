# Research loop and current next decision

Latest steering: seek substantial results about important modern
cryptographic problems; RSA, AES, SHA-256 are examples, not a closed list.
This changes the immediate priority from the frozen Ascon comparison work.

Current primary target: RSA short-relation root recovery (MNV Q2).
Next: derive a rigorous treatment of common components, test the precise
projection obstruction on small exact instances, and determine whether a
support/height argument can go beyond the known bound. Before an expensive
computation, require a reason it can decide one of these mathematical gaps.

Cycle after each finding:
1. State exact new constraint, candidate or failure and its scope.
2. Check definitions, then equivalent prior formulations.
3. If useful, construct a checkable proof/certificate and seek independent
   review only for a substantive candidate.
4. Freeze and publish verified own-scope work, retaining failures.
5. Choose the next concrete unresolved step; if several mechanisms fail,
   close that route explicitly and return to the source gate.

Success is not counted by local checks, pages, commits or famous algorithm
names. In particular, a standard linear-algebra/resultant identity is a
baseline unless it changes a meaningful cryptographic theorem or resource
bound. An unproved broad target stays open in the status record.

This plan describes active-session work and durable recovery. No unconfigured
background process or indefinite activity after session termination is claimed.
