# Actual inverse-restriction module self-equivalence

Let R be any commutative ring of characteristic two, q any element of R,
and H any unit. Write A for the actual noncommutative twenty-coordinate
table algebra and h_H for its actual dual-scaling R-algebra automorphism.

`TwentyDimDualScaleModule.lean` constructs the module-category
self-equivalence obtained by restricting scalars along h_H inverse.
For every actual left A-module M, its underlying elements and addition
are retained, with action

```text
a acting on x in F_H(M) = h_H inverse(a) acting on x in M.
```

Every actual module morphism keeps its underlying function. The functor
is additive and R-linear and preserves finite limits and finite colimits.
Its equivalence inverse is supplied by the actual ring-equivalence
restriction-of-scalars construction.

The actual f-character satisfies eps_f(h_H inverse(a)) = eps_f(a).
Consequently the source constructs an actual module isomorphism
eta_H : F_H(S_f) -> S_f whose two directions are the identity on elements.
Both directions are checked as A-linear morphisms for their respective
module structures, rather than merely identifying character values.

The ring R can have zero divisors, q can be zero, and no field or
nonzero-parameter condition is used. The inverse restriction convention
matches the left-module realization of the right twist.

The companion verification JSON records actual kernel compilation,
printed axiom audits, an independent replay and the exact source hash.
After the local dependencies have been compiled and the pinned Mathlib
cache installed, direct replay from this folder is:

```powershell
$env:LEAN_PATH = (Get-Location).Path + ';' + (Resolve-Path '..').Path
lake env lean TwentyDimDualScaleModule.lean
```

The package pins Lean 4.34.1 and Mathlib commit
`d13f23b723b8a846827a245b89c10fc7d3f11612`. A local dependent source can
use an ignored `.olean` generated by adding
`-o TwentyDimDualScaleModule.olean` to that command.

This source supplies the actual module functor and character endpoint
isomorphism. The canonical map on Ext and the comparison with the fixed
cochain or projective resolution require separate sources.
