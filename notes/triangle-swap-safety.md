# 局部三角形交换的全局安全性：一个精确小反例

本笔记给出一个七顶点简单图：两个三角形的局部交换提高了局部顶点支撑，却与保留的第三个三角形共用一条边。即使原打包同时具有最大大小和最大顶点支撑，这个局部条件仍然不充分。结果涉及交换规则的准确假设，不是否定原始 Tuza 猜想；本例的三角形边覆盖数与最大边不交打包数均为 3。

## 来源与准确范围

[Sheng–Xiao，arXiv:2308.16515v1，§4.2 的 Reduction Rule 8](https://arxiv.org/html/2308.16515v1) 将候选新三角形限制在“打包外顶点与旧两个三角形顶点”的诱导图内，要求新两个三角形互不重边，并增加二者的顶点并集大小。这些局部条件没有直接禁止重用其他保留三角形的边。

本文严格针对这个已经读到的字面条件。[作者于 2024-01-23 上传的会议论文全文](https://www.researchgate.net/publication/376376955_A_Discharging_Method_Improved_Kernels_for_Edge_Triangle_Packing_and_Covering) 中也有相同措辞。另有正式期刊版本 *Kernelization for edge triangle packing and covering via a discharging method*, Theoretical Computer Science 1004 (2024), 114635，[DOI](https://doi.org/10.1016/j.tcs.2024.114635)；当前只取得其摘要与部分预览，没有核准其规则正文，不能把上述措辞判断延伸到该版本。

反例没有否定加入全局兼容条件后的交换，也没有否定整个核化定理或充放电方法。不作历史首次发现或首次形式化声明。

## 实际图及完整三角形列表

令顶点为七个不同元素 \(u,v,w,x,y,z,f\)，边集为

\[
\{uv,uw,vw,vx,vy,xy,ux,uz,xz,uf,xf,wy\}.
\]

图恰有以下六个三角形：

\[
uvw,\quad uvx,\quad uxz,\quad uxf,\quad vwy,\quad vxy.
\]

取全局打包 \(P=\{uvw,vxy,uxz\}\)，要替换的旧对为 \(O=\{uvw,vxy\}\)。打包外的顶点集恰为 \(U=\{f\}\)。新对取 \(N=\{uxf,vwy\}\)。

\(O\subseteq P\)，两对各有两个真实三角形，且各自在内部互不重边。新对位于 \(G[U\cup V(O)]\) 中；旧对顶点并集大小为 5，新对为 6。然而

\[
(P\setminus O)\cup N=\{uxz,uxf,vwy\}
\]

中的 \(uxz\) 与 \(uxf\) 共用真实图边 \(ux\)。所以新集合不是三角形打包，即使其顶点支撑已经增加到 7。

## 最大性与前置图条件

\(P\) 的三个三角形互不重边。若图有四个互不重边三角形，它们的十二条边会覆盖全部图边，使各顶点度数均为偶数；但 \(u,x\) 的度数为 5，\(w,y\) 的度数为 3，矛盾。因此 \(\nu(G)=3\)。

顶点 \(z,f\) 分别只处于 \(uxz,uxf\)，这两个三角形共用 \(ux\)，所以任一打包都不能同时包含两个顶点。\(P\) 的六点支撑因而也是所有最大打包中的最大支撑。

三条边 \(uv,ux,vy\) 覆盖完整六三角形列表，故 \(\tau(G)\le3\)；打包 \(P\) 又强制 \(\tau(G)\ge3\)。本例满足 \(\tau(G)=\nu(G)=3\)，明确满足 Tuza 不等式。

每条边与每个顶点都在三角形中；图无 \(K_4\)。每个顶点的邻居诱导图均连通，因而不存在将 incident 边划分为两个非空部分、同时无三角形跨越两部分的顶点 split。旧打包最大又排除了打包增广。取决策阈值 \(k=4\) 时，所读来源中 Rule 8 之前的终止、图删除与增广条件均不会消除这个例子。这些前置条件以及覆盖数的等式另有精确 Python 检查与独立数学证明；本 Lean 文件没有形式化这些额外条件。

## 安全交换所需条件

一个充分修补是：新对的每条边都必须避开所有保留三角形的边。也可以直接要求交换后的全局集合仍是具有所需大小的打包。使用剩余边与被替换旧三角形边组成的边诱导子图，也可保证边的兼容性。

在来源所规定的诱导顶点限制下，局部并集增加确实保证整个新集合的顶点并集增加：新增顶点全部来自原打包外，而与保留三角形共享的旧顶点只会减少交换造成的顶点损失。因此这里的缺陷是全局边兼容性，而不是顶点并集的比较。

## Lean 与复现

源文件为 [TriangleSwapSafety.lean](proof/TriangleSwapSafety.lean)。它定义实际 Mathlib `SimpleGraph (Fin 7)`，用 `Sym2` 表示无序边；证明展示的十二边集就是图的实际边集，三角形判据使用真实图邻接。完整三角形列表覆盖任意三点完全子图。

最大性检查只使用这六个三角形的 64 个子集，并用完整列表的桥接证明推广到任意实际图打包；不把受限候选表当作全部打包。最终声明 `maximum_support_local_swap_counterexample` 同时包含原全局打包、两个最优性条件、完整局部交换假设和全局失败。`local_condition_not_sufficient` 否定局部条件普遍保证全局安全的断言。

本文件使用普通内核检查的 `decide`，不用 `native_decide`、自定义公理或占位证明。正式编译和独立回放状态以 [验证记录](results/triangle-swap-safety.json) 为准。对具体有限证书的 Lean 证明，不等于形式化或否定整个来源算法。


精确图检查可以独立运行：

~~~sh
python notes/check_triangle_swap_safety.py
~~~

它枚举图的全部三角形、64 个候选子集与有限边覆盖，并检查全部顶点 link 的连通性；仅针对这个固定小图。其结果见 [精确记录](results/triangle-swap-exact.json)。
